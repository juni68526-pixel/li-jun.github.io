SPACE LAB 웹 포트폴리오 — GitHub Pages 올리는 법

1. github.com 가입 (아이디: li-jun)
2. 오른쪽 위 + → New repository → 이름: li-jun.github.io → Public → Create repository
3. 빈 저장소 화면에서 "uploading an existing file" 클릭
4. 이 폴더 안의 index.html 과 img 폴더(영상이 있으면 video 폴더도)를 함께 끌어다 놓기 → Commit changes
5. Settings → Pages → Branch: main / (root) → Save (이미 켜져 있으면 그대로)
6. 1~3분 뒤 접속: https://li-jun.github.io/

수정할 때: 빌더 1단계에 이 zip을 다시 올리면 이어서 고칠 수 있습니다. 고친 뒤 다시 내려받아 4번처럼 덮어 올리세요.
video 폴더가 있으면 함께 올리세요. GitHub 웹 업로드는 파일당 25MB까지입니다.
portfolio-data.json 은 작업 데이터입니다. GitHub에 올려도 되고 안 올려도 됩니다.

SPACE LAB 网页作品集 — 上传到 GitHub Pages 的方法

1. 在 github.com 注册（用户名：li-jun）
2. 右上角 + → New repository → 名称：li-jun.github.io → Public → Create repository
3. 在空仓库页面点击 "uploading an existing file"
4. 把此文件夹里的 index.html 和 img 文件夹一起拖进去 → Commit changes
5. Settings → Pages → Branch: main / (root) → Save（已开启则不用改）
6. 1~3 分钟后访问：https://li-jun.github.io/
